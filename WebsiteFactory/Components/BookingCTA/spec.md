# Component — BookingCTA

Repeated mid-page and end-of-page call-to-action block, distinct from the
AvailabilityStrip's persistent top-of-page CTA. Slightly larger, can
include a short reassurance line ("No obligation, cancel anytime" — only
if true for this business).

Props: `headline`, `subtext`, `ctaLabel`, `onCtaClick`, `phone` (optional,
renders a secondary "or call" link).
