# Stage 06 — QA

**Input:** `website/src/`, `Standards/quality-standards.md`

**Output:** `Businesses/<slug>/website/qa-report.md`

## Steps

1. Run `Skills/qa-review.md` and `Skills/accessibility-review.md` in
   full — every line item in `Standards/quality-standards.md` gets an
   explicit pass/fail in the report, not a summary judgment.
2. Any fail goes back to Build (stage 05) with a specific, actionable
   note — not a vague "needs polish."
3. Only when every item passes: write the final `qa-report.md`, update
   `status.md`, and set `queue.json` `stage: "deploy"`.

QA is a gate, not a formality — a business does not move to deploy on a
partial pass.
