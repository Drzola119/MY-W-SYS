# Template — Gym / Fitness Studio

## Tone
Direct, energetic, punchier sentences than the dental template. This
audience wants momentum, not reassurance.

## Page structure

1. Hero + `AvailabilityStrip` (open now / next class starts)
2. Class schedule / programs offered
3. Trainer bios (`StaffBios`) — real, from research
4. Membership tiers — real pricing if published; if not published, a
   "get pricing" CTA rather than an invented number
5. `ReviewsTicker`
6. Facility gallery (real photos of the actual space)
7. FAQ (trial class, what to bring, cancellation policy)
8. `ContactLocation`

## CTA priority
Book a free trial class > View schedule > Get membership pricing.

## SEO focus
`[city] gym`, `personal trainer [city]`, `[niche] classes [city]` (e.g.
"HIIT classes Manchester" if that's what they actually run).
