# Handoff Log

End-of-session notes at the factory level (not per-business — see
`Businesses/<slug>/status.md` for that). Useful when a session worked
across multiple businesses or made a system change mid-session.

Format:
```
## YYYY-MM-DD HH:MM — <session/worktree>
What was touched, what's left, anything the next session should know
before continuing.
```

(empty — add entries as they come up)
