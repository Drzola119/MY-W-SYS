# Skill — Generate Copy

Given `brand/voice.md`, `Design-Systems/local-services/voice-and-copy.md`,
and `research/*.md`, write copy for one page at a time into
`website/copy/<page>.md`.

Rules:
- Every claim must trace back to something in `research/`. If you want
  to say something research doesn't support, don't say it — flag the
  gap instead.
- Active voice, specific over aspirational (see voice-and-copy.md).
- CTA button copy states the action's actual result, not "Submit" or
  "Learn more."
- Write headings and body separately so Build can map them to the
  right components without re-parsing prose.
